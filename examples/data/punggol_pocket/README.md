# Archived: `punggol_pocket`

This directory is an older, smaller Punggol extract (different bbox,
date, and Sentinel-2 band set). **Do not use it for tutorials or
new scripts.**

Canonical fixture:

```text
examples/data/real/punggol
```

Kept only so historical gallery PNGs and the single-photo
`layers/streetview.jpg` contract remain inspectable. New work must
load `examples/data/real/punggol` and street-view photos from
`examples/data/real/streetview/punggol`.
