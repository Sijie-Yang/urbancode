# Thermal Comfort in Sight case data

Photos are Wikimedia Commons files already stored under
`examples/data/real/streetview/punggol/`. Each file keeps its original
license (CC BY-SA 4.0). See that catalog for author, URL, and checksum.

TCIS model weights are not stored here. They are downloaded to the
UrbanCode cache from Hugging Face (`sijiey/Thermal-Affordance-Model`)
when `uc.perception.thermal_affordance()` runs.

Paper: Yang et al., 2024. Thermal Comfort in Sight.
https://arxiv.org/abs/2410.11887
Project: https://github.com/Sijie-Yang/Thermal-Comfort-In-Sight
