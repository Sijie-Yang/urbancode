uc --version
============

Question
--------

Which UrbanCode version is installed?

Expected output
---------------

.. figure:: /_static/recipes/cli/version.png
   :alt: Terminal-style preview of uc --version
   :width: 100%

   ``uc --version`` prints ``urbancode <version>`` and exits.

Installation
------------

``pip install urbancode`` (core wheel).

Minimal command
---------------

::

   uc --version
